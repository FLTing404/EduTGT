# 方向调整与目录说明

整理日期：2026-10-29（Asia/Shanghai）。当前处于初期探索阶段。

## 旧尝试与当前工作

此前 [EduTGT 固定版本](https://github.com/FLTing404/EduTGT/tree/dbeb7d42e656967c3eb3b0c4f69f9f64d73201d4) 的主任务是 OULAD 学生—学习资源交互的时序图链路预测，并包含课程通过预测。当前目录转向下一次作答正确性预测及其评估，保留前期 FC-HGNN 趋势复现作为起点，继续比较超图候选、序列基线与错误敏感决策。

| 项目 | 旧 EduTGT | 当前分支 |
| --- | --- | --- |
| 主要任务 | 时序图链路预测、课程通过预测 | 下一次作答正确性、错误识别与阈值评估 |
| 数据接口 | 学生—资源事件图及下游标签 | 学生作答序列、题目、知识点、因果掩码 |
| OULAD 的作用 | 点击交互图和课程下游任务 | `studentAssessment` 评测序列，分数 ≥ 40 作为达标标签 |
| 主入口 | `EduTGT/`、`downstream_pass_prediction/` | `reproduction/test_new_datasets.py`、`reproduction/run.py` |
| 结果解读 | 历史图学习及课程预测记录 | 短预算候选比较、消融、错误识别与误报折中 |

旧模型和当前模型的任务、目标及划分不同，已有分数不能直接横比。当前 OULAD 的课程模块呈现仅作为粗粒度知识点代理；它与细粒度逐题 KT 数据有明显区别。

## 整合方式

新分支 `research/kt-exploration-20261029` 继承旧仓库提交历史，以当前目录替换分支中的工作树。旧代码和结果可以从上面的固定提交完整查看。新分支不同时保留两套运行目录，便于确定当前入口、依赖和数据协议。

当前保持 `reproduction/` 与 `datasets/` 同级，因此无需搬动模型代码或改写配置路径。统一根 `requirements.txt` 指向当前运行依赖；测试依赖单独列在 `reproduction/requirements-dev.txt`。

保留六套数据的来源、许可、校验和和统计；原始数据与派生训练数据由本地工作区管理。汇报材料保留实验事实、文献背景和验证问题，移除本项目初稿、投稿定位和成稿安排。参考论文和前期尝试仅作研究背景。

## 继续验证的问题

1. 扩大训练预算，检查强序列基线与候选模型是否充分收敛。
2. 在相同输入、辅助目标和调参预算下验证超图传播的独立作用。
3. 比较不同阈值目标下的错误检出、误报比例、概率校准与假设成本。
4. 核实目标事件时间的可用性，并完善 NIPS 同分钟并列事件的严格时序协议。

现有结果和限制详见 [项目综合汇报](../汇报材料/项目综合汇报.md) 与 [新数据集实验简报](../汇报材料/新数据集双方向实验简报.md)。
