# EduTGT 代码执行使用指南

> **文档导航**：总索引见 **[README.md](./README.md)**；**方法思路与 ContraTGT 对比**见 **[方法与ContraTGT对比.md](./方法与ContraTGT对比.md)**。

本文汇总仓库内**常用脚本的工作目录、命令行与参数**。默认以 **Linux / macOS** 的 `bash` 为例；**Windows PowerShell** 下请将多条命令间的 `&&` 改为分号 `;`，或逐条执行。

---

## 1. 工作目录约定

| 说明 | 路径（相对仓库） |
|------|------------------|
| **训练方法脚本**（`methods/main.py` 等） | `EduTGT/EduTGT/methods/`（须从父目录执行） |
| **OULAD 预处理脚本** | `EduTGT/EduTGT/data/scripts/preprocess_oulad_for_contratgt.py` |
| **原始 OULAD CSV**（默认） | `EduTGT/EduTGT/data/raw/OULAD/` |
| **预处理输出**（默认） | `EduTGT/EduTGT/data/processed/data_<名称>/` |

以下凡写 `cd ...`，均指进入 **`EduTGT/EduTGT`**（含 `pretrain.py`、`run_*.py` 的那一层）。

```bash
cd /path/to/你的仓库/EduTGT/EduTGT
```

---

## 2. 依赖与环境

- Python 3；需安装 **PyTorch**、**pandas**、**numpy**、**scipy**、**scikit-learn**、**tqdm** 等（与 `main.py` import 一致）。
- 有 GPU 时安装对应 CUDA 版 PyTorch；无 GPU 时脚本会回退 CPU。

```bash
# 示例（按你本机 CUDA 版本调整）
pip install torch pandas numpy scipy scikit-learn tqdm
```

## 3. OULAD 数据预处理

**脚本**：`data/scripts/preprocess_oulad_for_contratgt.py`  
**建议执行目录**：`EduTGT/EduTGT`（这样默认 `raw_dir`、`out_root` 与 README 一致）

### 3.1 参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--raw_dir` | `data/raw/OULAD`（相对项目根 `EduTGT/EduTGT`） | 含 `courses.csv`、`studentVle.csv`、`vle.csv` 等的目录 |
| `--out_root` | `data/processed` | 输出根目录，其下生成 `data_<模块或实例>/` |
| `--module` | **必填** | `AAA`、`BBB`、…、`GGG`（整模块）；`AAA-2013J`（单实例，须在白名单）；`ALL`（按顺序跑 AAA→…→GGG 整模块）。**均为学生–VLE 站点二部图** |

### 3.2 命令示例

```bash
cd EduTGT/EduTGT

# 整模块 -> data/processed/data_AAA/
python data/scripts/preprocess_oulad_for_contratgt.py --module AAA

# 单实例 -> data/processed/data_AAA_2013J/
python data/scripts/preprocess_oulad_for_contratgt.py --module AAA-2013J

# 一次生成全部模块（不含单实例子目录）
python data/scripts/preprocess_oulad_for_contratgt.py --module ALL
```

**说明**：若你本机仍保留旧版目录名 `data_*_vlesite/`，请重新跑预处理或自行改名，使 `--data_dir` 的最后一级与 `outputs/pretrain/<文件夹名>.pth` 一致。

**整模块图（多 presentation）**：若要用 **课程实例关系** 做预训练/消融偏置负采样，请在对应数据目录生成 `pres_relation.json`：

```bash
python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA
```

### 3.3 自定义原始数据 / 输出位置

```bash
python data/scripts/preprocess_oulad_for_contratgt.py \
  --raw_dir /绝对路径/OULAD_csv \
  --out_root /绝对路径/输出根 \
  --module BBB
```

## 4. 预训练 `pretrain.py`

**执行目录**：`EduTGT/EduTGT`  
**读取**：`--data_dir` 下的 `ml_*.csv` 与 `*.content`  
**写出**：`outputs/pretrain/<数据文件夹名>.pth`、`outputs/middle/`、`outputs/checkpoints/`（与 `utils.EarlyStopping` 配置一致）

### 4.1 参数说明（与 `main.py` 共用 `utils.get_args()`）

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--data_dir` | `None`（**OULAD 流程下请必传**） | 数据目录，如 `data/processed/data_AAA_2013J` |
| `-d` / `--data` | `slashdot` | **未传 `--data_dir` 时**走官方 ContraTGT 内置数据名 |
| `--n_epoch` | `50` | 训练轮数上限 |
| `--bs` | `800` | batch size |
| `--lr` | `1e-3` | 学习率（`pretrain.py` 内优化器仍硬编码 `1e-3`，与命令行 `lr` 并存时请知悉） |
| `--ctx_sample` | `40` | 空间邻居采样长度（`main` 默认用此值） |
| `--tmp_sample` | `31` | 时间序列采样长度（`main` 默认用此值） |
| `--drop_out` | `0.2` | Dropout |
| `--gpu` | `0` | GPU 编号；无 CUDA 时忽略 |
| `--seed` | `60` | 随机种子 |
| `--tolerance` | `0` | EarlyStopping 相对改进阈值 |
| `--aug_len` | `1.5` | 预训练里 Top-k / 增广序列长度缩放 |
| `--pres_relation` | `None` | 指向 `pres_relation.json`；`None` 时若 `data_dir` 下存在该文件则 **自动加载**，训练期负样本 `dst` 按 W 偏置 |
| `--pres_mix_uniform` | `0.35` | 偏置与均匀负采样的混合比例（越大越接近原均匀采样） |
| `--ngh_cache` | 关闭 | 一般不推荐开启 |

### 4.2 命令示例

```bash
cd EduTGT/EduTGT

python pretrain.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800
python pretrain.py --data_dir data/processed/data_AAA --n_epoch 50 --bs 800 --gpu 0 --drop_out 0.2
```

## 5. 方法脚本（`methods/` 目录）

所有训练方法脚本统一放在 **`methods/`** 子目录，与工具脚本分开。

| 脚本 | 说明 |
|------|------|
| `methods/main.py` | ContraTGT 微调基线（均匀负采样） |
| `methods/main_ablation_pres_relation.py` | **EduTGT 主方法** — pres 关系偏置负采样 |
| `methods/main_ablation_student_temporal.py` | 消融：学生时序一致性损失（STC） |
| `methods/main_ablation_course_progress.py` | 消融：课程进度归一化时间戳（[0,1]） |

**执行目录**：始终在 **`EduTGT/EduTGT`**（`methods/` 的父目录）。各 `methods/*.py` 会在启动时把项目根加入 `sys.path`，一般**无需**再设 `PYTHONPATH`；若你仍用旧版脚本或自定义入口，可保留 `PYTHONPATH=.`（Linux/macOS）或 `$env:PYTHONPATH="."`（PowerShell）。

### 5.1 直接运行单个方法

```bash
cd EduTGT/EduTGT

# ContraTGT 基线
python methods/main.py --data_dir data/processed/data_AAA --n_epoch 50 --bs 800

# EduTGT 主方法（pres 偏置采样，λ=0.35）
python methods/main_ablation_pres_relation.py \
    --data_dir data/processed/data_AAA --n_epoch 50 --bs 800 --pres_mix_uniform 0.35

# 消融：STC 损失
python methods/main_ablation_student_temporal.py \
    --lambda_tc 0.1 --data_dir data/processed/data_AAA --n_epoch 50 --bs 800

# 消融：课程进度时间编码（归一化时间戳到 [0,1]）
python methods/main_ablation_course_progress.py \
    --data_dir data/processed/data_AAA --n_epoch 50 --bs 800 --pres_mix_uniform 0.35
```

> **注意**：`main_ablation_pres_relation.py` 和 `main_ablation_course_progress.py` 依赖 `pres_relation.json`，请先执行：
> ```bash
> python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA
> ```

## 6. 一键消融批跑 `run_ablation_batch.py`

**执行目录**：`EduTGT/EduTGT`  
**行为**：对 4 种消融方法 × N 个 seed 顺序运行并写 CSV（不含预训练）。

**4 种消融方法**：

| 方法标签 | 消融含义 |
|----------|---------|
| `ablation_pres` | EduTGT 主方法（pres 偏置负采样，λ=0.35） |
| `ablation_stc` | ContraTGT + 学生时序一致性损失 |
| `ablation_no_temporal` | 去掉时序分支（tmp\_sample=1，仅保留空间上下文） |
| `ablation_course_progress` | 课程进度感知时序编码（时间戳归一化到 [0,1]） |

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--dataset` | **必填** | AAA～GGG，对应 `data/processed/data_<MODULE>` |
| `--seeds` | `1,2,3,4,5` | 逗号分隔的整数 seed |
| `--n_epoch` | `50` | 训练轮数 |
| `--bs` | `800` | batch size |
| `--lr` | `1e-3` | 学习率 |
| `--ctx_sample` | `40` | 空间邻居采样数 |
| `--tmp_sample` | `31` | 时序邻居采样数（ablation\_no\_temporal 自动覆盖为 1） |
| `--drop_out` | `0.2` | Dropout |
| `--gpu` | `0` | GPU 编号 |
| `--lambda_tc` | `0.1` | 仅 ablation\_stc 使用 |
| `--out_csv` | 自动生成 | 输出 CSV 路径 |

```bash
cd EduTGT/EduTGT

# 前置：生成 pres_relation.json（若已有可跳过）
python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA

# 一键跑 4 种消融 × 5 seed（共 20 个任务）→ outputs/result/ablation_AAA_<时间戳>.csv
python run_ablation_batch.py --dataset AAA

# 指定数据集和 seed
python run_ablation_batch.py --dataset CCC --seeds 1,2,3,4,5

# 自定义更多参数
python run_ablation_batch.py --dataset AAA --seeds 42,2,2026,7,99 --gpu 0 --n_epoch 50
```

**输出**：`outputs/result/ablation_<DATASET>_<时间戳>.csv`

## 7. 一键对比算法批跑 `run_baselines_batch.py`

**执行目录**：`EduTGT/EduTGT`  
**行为**：对 TGN / TGAT / JODIE 三个基线顺序执行（共用同一 seed）并写 CSV。

**前置**：
```bash
pip install -r baseline/requirements-baseline.txt
```

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--dataset` | **必填** | AAA～GGG |
| `--seed` | `42` | 随机种子（单个整数） |
| `--epochs` | `50` | 训练轮数 |
| `--batch_size` | `200` | batch size |
| `--lr` | `1e-3` | 学习率 |
| `--device` | `cuda` | `cuda` 或 `cpu` |
| `--out_csv` | 自动生成 | 输出 CSV 路径 |

```bash
cd EduTGT/EduTGT

# 一键跑 TGN / TGAT / JODIE，seed=42 → outputs/result/baselines_AAA_<时间戳>.csv
python run_baselines_batch.py --dataset AAA

# 指定数据集和 seed
python run_baselines_batch.py --dataset CCC --seed 42

# CPU 环境
python run_baselines_batch.py --dataset AAA --seed 2026 --device cpu
```

**输出**：`outputs/result/baselines_<DATASET>_<时间戳>.csv`

## 9. Baseline 对比实验 `baseline/`

**执行目录**：`EduTGT/EduTGT`  
**作用**：在 **与 `main.py` 相同** 的 `data_dir`、`ml_*.csv`、`*.content` 及 `utils.Dataset` 时间分位划分下，顺序训练 **TGN**（PyG `TGNMemory`）、**TGAT**（PyTorch 结构对齐论文 + 复用 `sampling.get_neighbor_list`）、**JODIE 风格**（目录名为 `baseline/tncn/`，替代 TNCN，理由见 `baseline/tncn/README.md`）。评估与 **ContraTGT（IJCAI）/ `main.py`** 一致：除全量 **test** 外，另输出 **new node test（`nn_test`）** 的 AUC/AP/ACC；结果见各 `result.json` 与 `summary.csv`。

**依赖**：TGN 需额外安装 `torch-geometric`：

```bash
pip install -r baseline/requirements-baseline.txt
```

**一键运行**：

```bash
cd EduTGT/EduTGT
python baseline/run_all_baselines.py --data_dir data/processed/data_AAA_2013J
```

可选：`--epochs`、`--batch_size`、`--lr`、`--seed`（默认 42）、`--device cuda|cpu`；`--skip_tgn`、`--skip_tgat`、`--skip_tncn` 跳过某一基线。

**单模型**：

```bash
python baseline/tgn/runner.py --data_dir data/processed/data_AAA_2013J
python baseline/tgat/runner.py --data_dir data/processed/data_AAA_2013J
python baseline/tncn/runner.py --data_dir data/processed/data_AAA_2013J
```

**写出**：`baseline/results/<数据目录名>/` 下各子目录的 `result.json`、`checkpoint.pt`，以及 `summary.csv`、`summary.json`。详见 **`baseline/README.md`**。

## 11. 训练结果记录

`methods/` 下各方法脚本结束后会向 **`outputs/logs/training_runs.jsonl`** 追加一行 JSON，并打印 `[RESULT] ...`。

主要字段：`ended_at`、`run_type`（`baseline` / `ablation_pres_relation` / `ablation_course_progress` 等）、`data_name`、超参、`metrics.test`（auc/ap/acc/loss）、`metrics.nn_test`、`training.best_epoch`。

## 12. OULAD 数据格式速查

**预处理输出目录**（`data/processed/data_<MODULE>/`）包含：

| 文件 | 说明 |
|------|------|
| `ml_<MODULE>.csv` | 边列表，列：`,u,i,ts,label,idx`；`ts = pres_index×1000 + date`（相对日）；全部 `label=1` |
| `<MODULE>.content` | 节点特征矩阵，无表头，每行一个节点，特征维 71（含学生人口属性 + VLE 活动类型 one-hot 等） |
| `stats.json` | 规模统计（num_students / num_site_nodes / num_edges 等） |
| `pres_relation.json` | 课程实例站点 Jaccard 相似矩阵 W（pres 偏置采样依赖） |
| `node_map.csv` | 内部节点 id → 原始 OULAD id |
| `train/val/test/nn_val/nn_test _idx.txt` | 各切分边下标 |

**时间切分**（与 ContraTGT 一致）：对全体边 `ts` 取 **10% / 20% 分位数** 为阈值，划分 train / val / test（时间外推，非随机留出）。

**节点类型**：学生节点（src）+ VLE 站点节点（dst），构成二部图；负样本为替换 `dst` 的随机 VLE 站点 id。

**特征维对齐**：Transformer 要求 4 的倍数，`main.py` / `pretrain.py` 会自动右侧零填充（不修改磁盘文件）。

## 13. 推荐最小流程（OULAD → 训练）

```bash
cd EduTGT/EduTGT

# 1) 预处理（示例：单实例）
python data/scripts/preprocess_oulad_for_contratgt.py --module AAA-2013J

# 2) 预训练
python pretrain.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800

# 3) EduTGT 主方法微调（pres 偏置负采样）
python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA_2013J
python methods/main_ablation_pres_relation.py \
    --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800 --pres_mix_uniform 0.35

# 3b) 可选：ContraTGT 基线对比
python methods/main.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800

# 4) 可选：一键消融实验（4 种方法 × 5 seed → CSV）
python run_ablation_batch.py --dataset AAA --seeds 1,2,3,4,5

# 5) 可选：一键对比算法实验（TGN / TGAT / JODIE × 1 seed → CSV）
pip install -r baseline/requirements-baseline.txt
python run_baselines_batch.py --dataset AAA --seed 42
```
