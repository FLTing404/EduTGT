# EduTGT 代码执行使用指南

> **文档导航**：总索引见 **[README.md](./README.md)**；**方法思路与 ContraTGT 对比**见 **[方法与ContraTGT对比.md](./方法与ContraTGT对比.md)**。  
> 若你从旧目录结构升级，请先阅读 **[MIGRATION_CD.md](./MIGRATION_CD.md)**（`data/processed`、`outputs/` 等）。

本文汇总仓库内**常用脚本的工作目录、命令行与参数**。默认以 **Linux / macOS** 的 `bash` 为例；**Windows PowerShell** 下请将多条命令间的 `&&` 改为分号 `;`，或逐条执行。

---

## 1. 工作目录约定

| 说明 | 路径（相对仓库） |
|------|------------------|
| **训练与推理入口**（`main.py`、`pretrain.py` 等） | `EduTGT/EduTGT/`（与 `main.py` 同级执行） |
| **OULAD 预处理脚本** | `EduTGT/EduTGT/data/scripts/preprocess_oulad_for_contratgt.py` |
| **原始 OULAD CSV**（默认） | `EduTGT/EduTGT/data/raw/OULAD/` |
| **预处理输出**（默认） | `EduTGT/EduTGT/data/processed/data_<名称>/` |

以下凡写 `cd ...`，均指进入 **`EduTGT/EduTGT`**（含 `main.py` 的那一层）。

```bash
cd /path/to/你的仓库/EduTGT/EduTGT
```

## 2. 依赖与环境

- Python 3；需安装 **PyTorch**、**pandas**、**numpy**、**scipy**、**scikit-learn**、**tqdm** 等（与 `main.py` import 一致）。
- 有 GPU 时安装对应 CUDA 版 PyTorch；无 GPU 时脚本会回退 CPU。

```bash
# 示例（按你本机 CUDA 版本调整）
pip install torch pandas numpy scipy scikit-learn tqdm
```

## 3. OULAD 数据预处理

**脚本**：`data/scripts/preprocess_oulad_for_contratgt.py`  
**建议执行目录**：`EduTGT/EduTGT`（这样默认 `raw_dir`、`out_root` 与 README 一致）

### 3.1 参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--raw_dir` | `data/raw/OULAD`（相对项目根 `EduTGT/EduTGT`） | 含 `courses.csv`、`studentVle.csv`、`vle.csv` 等的目录 |
| `--out_root` | `data/processed` | 输出根目录，其下生成 `data_<模块或实例>/` |
| `--module` | **必填** | `AAA`、`BBB`、…、`GGG`（整模块）；`AAA-2013J`（单实例，须在白名单）；`ALL`（按顺序跑 AAA→…→GGG 整模块）。**均为学生–VLE 站点二部图** |

### 3.2 命令示例

```bash
cd EduTGT/EduTGT

# 整模块 -> data/processed/data_AAA/
python data/scripts/preprocess_oulad_for_contratgt.py --module AAA

# 单实例 -> data/processed/data_AAA_2013J/
python data/scripts/preprocess_oulad_for_contratgt.py --module AAA-2013J

# 一次生成全部模块（不含单实例子目录）
python data/scripts/preprocess_oulad_for_contratgt.py --module ALL
```

**说明**：若你本机仍保留旧版目录名 `data_*_vlesite/`，请重新跑预处理或自行改名，使 `--data_dir` 的最后一级与 `outputs/pretrain/<文件夹名>.pth` 一致。

**整模块图（多 presentation）**：若要用 **课程实例关系** 做预训练/消融偏置负采样，请在对应数据目录生成 `pres_relation.json`：

```bash
python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA
```

### 3.3 自定义原始数据 / 输出位置

```bash
python data/scripts/preprocess_oulad_for_contratgt.py \
  --raw_dir /绝对路径/OULAD_csv \
  --out_root /绝对路径/输出根 \
  --module BBB
```

## 4. 预训练 `pretrain.py`

**执行目录**：`EduTGT/EduTGT`  
**读取**：`--data_dir` 下的 `ml_*.csv` 与 `*.content`  
**写出**：`outputs/pretrain/<数据文件夹名>.pth`、`outputs/middle/`、`outputs/checkpoints/`（与 `utils.EarlyStopping` 配置一致）

### 4.1 参数说明（与 `main.py` 共用 `utils.get_args()`）

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--data_dir` | `None`（**OULAD 流程下请必传**） | 数据目录，如 `data/processed/data_AAA_2013J` |
| `-d` / `--data` | `slashdot` | **未传 `--data_dir` 时**走官方 ContraTGT 内置数据名 |
| `--n_epoch` | `50` | 训练轮数上限 |
| `--bs` | `800` | batch size |
| `--lr` | `1e-3` | 学习率（`pretrain.py` 内优化器仍硬编码 `1e-3`，与命令行 `lr` 并存时请知悉） |
| `--ctx_sample` | `40` | 空间邻居采样长度（`main` 默认用此值） |
| `--tmp_sample` | `31` | 时间序列采样长度（`main` 默认用此值） |
| `--drop_out` | `0.2` | Dropout |
| `--gpu` | `0` | GPU 编号；无 CUDA 时忽略 |
| `--seed` | `60` | 随机种子 |
| `--tolerance` | `0` | EarlyStopping 相对改进阈值 |
| `--aug_len` | `1.5` | 预训练里 Top-k / 增广序列长度缩放 |
| `--pres_relation` | `None` | 指向 `pres_relation.json`；`None` 时若 `data_dir` 下存在该文件则 **自动加载**，训练期负样本 `dst` 按 W 偏置 |
| `--pres_mix_uniform` | `0.35` | 偏置与均匀负采样的混合比例（越大越接近原均匀采样） |
| `--ngh_cache` | 关闭 | 一般不推荐开启 |

### 4.2 命令示例

```bash
cd EduTGT/EduTGT

python pretrain.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800
python pretrain.py --data_dir data/processed/data_AAA --n_epoch 50 --bs 800 --gpu 0 --drop_out 0.2
```

## 5. 微调（Baseline）`main.py`

**执行目录**：`EduTGT/EduTGT`  
**依赖**：已有 `outputs/pretrain/<数据文件夹名>.pth`（`<数据文件夹名>` = `data_dir` 的最后一级，如 `data_AAA_2013J`）  
**写出**：`outputs/models/<数据文件夹名>.pth`、`outputs/checkpoints/<数据文件夹名>.pth`

### 5.1 参数说明

与 **第 4.1 节** 相同；微调阶段使用 `--lr` 作为 `Adam` 学习率。

### 5.2 命令示例（OULAD 导出数据）

```bash
cd EduTGT/EduTGT

python main.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800
python main.py --data_dir data/processed/data_AAA --n_epoch 50 --bs 800 --lr 0.001 --gpu 0
```

### 5.3 官方 ContraTGT 数据（未使用 `--data_dir`）

```bash
cd EduTGT/EduTGT
python main.py -d slashdot --n_epoch 50 --bs 800
```

（数据来自仓库内约定的 `data/ml_*.csv` 与 `node_feature/*.content`，与 OULAD 流程不同。）

## 6. 消融：presentation 关系负采样 `main_ablation_pres_relation.py`

**执行目录**：`EduTGT/EduTGT`  
**依赖**：同 `data_dir` 下存在 **`pres_relation.json`**（见第 3 节 `build_pres_relation.py`）；`outputs/pretrain/<data_name>.pth`（与 baseline 相同 backbone）  
**写出**：`outputs/models/<data_name>_pres_rel.pth`、`outputs/checkpoints/<data_name>_pres_rel.pth`

参数与 **`main.py` 一致**，另可使用 **`--pres_relation`**、**`--pres_mix_uniform`**（含义同预训练一节）。

**行为**：仅在 **训练阶段** 对负样本 `dst` 按当前边 `ts` 所在 presentation 与矩阵 **W** 偏置采样；验证/测试仍与 `main.py` 相同（均匀随机 `dst`）。

```bash
cd EduTGT/EduTGT
python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA
python main_ablation_pres_relation.py --data_dir data/processed/data_AAA --n_epoch 50 --bs 800
```

## 7. 消融：同学生时序一致性 `main_ablation_student_temporal.py`

**执行目录**：`EduTGT/EduTGT`  
**依赖**：`outputs/pretrain/<data_name>.pth`  
**写出**：`outputs/models/<data_name>_stc.pth`、`outputs/checkpoints/<data_name>_stc.pth`

| 额外参数 | 默认值 | 含义 |
|----------|--------|------|
| `--lambda_tc` | `0.1` | 时序一致性损失权重（须在其它参数前用 `parse_known_args` 解析，**推荐放在命令最前**） |

```bash
cd EduTGT/EduTGT
python main_ablation_student_temporal.py --lambda_tc 0.1 --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800
```

## 8. 一键消融 `run_ablation_experiments.py`

**执行目录**：`EduTGT/EduTGT`  
**行为**：依次调用 **presentation 关系负采样** 与 **时序一致性** 两个脚本（子进程）。

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `--data_dir` | **必填** | 与 `main.py` 相同 |
| `--n_epoch` | `50` | 传给两个子脚本 |
| `--bs` | `800` | batch size |
| `--lr` | `1e-3` | 学习率 |
| `--ctx_sample` | `40` | 空间采样 |
| `--tmp_sample` | `31` | 时间采样 |
| `--drop_out` | `0.2` | Dropout |
| `--gpu` | `0` | GPU |
| `--lambda_tc` | `0.1` | 仅第二个脚本使用 |
| `--pres_mix_uniform` | `0.35` | 仅第一个脚本：负采样均匀混合比例 |
| `--skip_pres` | 关闭 | 跳过 `main_ablation_pres_relation.py` |
| `--skip_edge` | 关闭 | 已弃用，等同于 `--skip_pres` |
| `--skip_stc` | 关闭 | 跳过 `main_ablation_student_temporal.py` |

```bash
cd EduTGT/EduTGT
python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA
python run_ablation_experiments.py --data_dir data/processed/data_AAA --n_epoch 50 --bs 800
python run_ablation_experiments.py --data_dir data/processed/data_AAA --skip_pres --lambda_tc 0.2
```

## 9. Baseline 对比实验 `baseline/`

**执行目录**：`EduTGT/EduTGT`  
**作用**：在 **与 `main.py` 相同** 的 `data_dir`、`ml_*.csv`、`*.content` 及 `utils.Dataset` 时间分位划分下，顺序训练 **TGN**（PyG `TGNMemory`）、**TGAT**（PyTorch 结构对齐论文 + 复用 `sampling.get_neighbor_list`）、**JODIE 风格**（目录名为 `baseline/tncn/`，替代 TNCN，理由见 `baseline/tncn/README.md`）。评估与 **ContraTGT（IJCAI）/ `main.py`** 一致：除全量 **test** 外，另输出 **new node test（`nn_test`）** 的 AUC/AP/ACC；结果见各 `result.json` 与 `summary.csv`。

**依赖**：TGN 需额外安装 `torch-geometric`：

```bash
pip install -r baseline/requirements-baseline.txt
```

**一键运行**：

```bash
cd EduTGT/EduTGT
python baseline/run_all_baselines.py --data_dir data/processed/data_AAA_2013J
```

可选：`--epochs`、`--batch_size`、`--lr`、`--seed`（默认 42）、`--device cuda|cpu`；`--skip_tgn`、`--skip_tgat`、`--skip_tncn` 跳过某一基线。

**单模型**：

```bash
python baseline/tgn/runner.py --data_dir data/processed/data_AAA_2013J
python baseline/tgat/runner.py --data_dir data/processed/data_AAA_2013J
python baseline/tncn/runner.py --data_dir data/processed/data_AAA_2013J
```

**写出**：`baseline/results/<数据目录名>/` 下各子目录的 `result.json`、`checkpoint.pt`，以及 `summary.csv`、`summary.json`。详见 **`baseline/README.md`** 与各子目录 **`README.md`**。

**批跑 main + 两消融 + 三 baseline（多 seed，汇总 CSV）**：独立脚本 **`run_batch_metrics_csv.py`**（不跑预训练），默认数据 **`data/processed/data_AAA` 或 `data_BBB`**，输出 **`outputs/result/*.csv`**。完整参数、CSV 列说明与 seed 行为见 **[run_batch_metrics_csv.md](./run_batch_metrics_csv.md)**（第 7 节）。

## 13. 推荐最小流程（OULAD → 训练）

```bash
cd EduTGT/EduTGT

# 1) 预处理（示例：单实例）
python data/scripts/preprocess_oulad_for_contratgt.py --module AAA-2013J

# 2) 预训练
python pretrain.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800

# 3) 微调（baseline）
python main.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800

# 4) 可选：消融 + 结果写入 outputs/logs/training_runs.jsonl（需先有 pres_relation.json）
python data/scripts/build_pres_relation.py --data_dir data/processed/data_AAA_2013J
python run_ablation_experiments.py --data_dir data/processed/data_AAA_2013J --n_epoch 50 --bs 800

# 5) 可选：与主模型公平对比的时序链路基线（需安装 baseline 依赖）
pip install -r baseline/requirements-baseline.txt
python baseline/run_all_baselines.py --data_dir data/processed/data_AAA_2013J
```
