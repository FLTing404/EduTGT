# NIPS 同分钟排序敏感性

状态：complete。

NIPS2020 Task 3/4 的 DateAnswered 只有分钟精度，68.015% 的事件处于同学生同分钟的并列组。主实验按 AnswerId 排序，敏感性实验在同分钟内固定种子随机重排；两者均无法恢复真实先后顺序。
