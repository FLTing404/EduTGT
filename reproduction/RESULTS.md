# FC-HGNN 初步性能趋势验证

运行日期：2026-09-19  
配置：`configs/smoke.yaml`  
随机种子：`20260824`  
划分：按学习者 70%/15%/15% 训练、验证、测试  
训练预算：最多 3 epochs，验证损失早停

## 结论

初步趋势为部分支持：FC-HGNN 在 EdNet 和 OULAD 上取得最高 AUC，并在 EdNet 上同时取得最高 Accuracy/F1；在 ASSIST12 的 800 人稀疏子集上未超过 DKT/SAINT-style。ASSIST12 子集中有 27,171 道题，训练用户仅 560 人，题目覆盖非常稀疏，超图与题目难度估计尚未充分学习。

OULAD 的正例率约 95.5%，Accuracy 和 F1 很容易被“全部预测正确”抬高，因此应以 AUC 和后续 PR-AUC 为主要判断指标。当前结果不能用于声称复刻原论文的绝对分数，只能说明超图和特征交叉在两套数据上呈现了有利趋势。

## 严谨性控制

- 经验题目难度只由训练用户计算，验证/测试标签没有参与特征构造。
- 用户级划分避免同一学习者跨集合泄漏。
- 原始数据、处理制品、配置和每个模型的逐 epoch 记录均保留。
- 所有未由论文说明的参数均在 YAML 和 README 中显式记录。
