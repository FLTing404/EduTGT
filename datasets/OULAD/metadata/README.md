# Open University Learning Analytics Dataset

## 文件

- `raw/anonymisedData.zip`
- ZIP 内含 7 张 CSV 表：`courses`、`assessments`、`vle`、`studentInfo`、`studentRegistration`、`studentAssessment`、`studentVle`

## 来源链

- Open University 官方页：https://research.stem.open.ac.uk/ouanalyse/dataset/
- 固定版本 DOI：https://doi.org/10.6084/m9.figshare.5081998.v1
- Figshare 文件 ID：`8606371`
- 原始文件名：`anonymisedData.zip`

Open University 官网当前的下载按钮返回 404，因此通过可追溯的 GitHub 缓存副本取得同一制品。文件大小为 46,750,706 字节，MD5 为 `7412686fd77cf0e0ee1e8c3e9b354308`，与 Figshare v1 公布值一致；ZIP CRC 全量检查通过。

## 数据核验

- `studentInfo` 注册记录：32,593
- 唯一学生：28,785
- 课程呈现：22
- `studentVle` 交互：10,655,280
- 其余表记录数：`studentAssessment` 173,912；`assessments` 206；`courses` 22；`studentRegistration` 32,593；`vle` 6,364
