# 新数据集实验的前沿基线差距

文献截止日期：2026-10-04。只纳入该日及以前公开的论文；这是本轮实验的定位说明，不包含额外训练结果。

本轮增强 FC-HGNN、相同输入的去超图消融及官方 AKT/simpleKT 对照，用于初步检验超图模块是否产生独立收益，以及错误敏感评估是否跨模型、跨新数据成立。本轮采用 8 轮训练筛选、最多 5,000 名学生的样本，尚未覆盖直接超图竞争者或各模型充分调参后的性能，因此当前结果只作为方向探索与下一轮验证的依据。

## 为什么论文分数不能直接横比

同为 ASSIST17，并不代表相同任务。DGEKT 正式论文保留 942,816 次交互，其正确率为 37.26%；MHAKT 清洗后只保留 248,462 次，并加入手工知识领域层级。序列截断、重复作答、支架/提示记录和多知识点处理会改变模型能看到的历史及评分事件。[DGEKT 表 2 与 §4.1](https://doi.org/10.1145/3638350)、[MHAKT §5.1 与附录 A](https://doi.org/10.1145/3803860)

DGEKT 正式期刊版设最大训练 600 轮，而作者仓库 README 写 20 轮；论文为 256 维交互嵌入，当前实验采用项目统一的 64 维配置与 8 轮筛选。应在同一管线上重新训练各模型，并核查论文版与仓库版差异，不能把短预算实验与原论文最优分数混成排行榜。[正式实现设置 §4.4](https://doi.org/10.1145/3638350)、[作者仓库设置](https://github.com/Yumo216/DGEKT)

增强模型与 AKT/simpleKT 的输入能力也有区别：项目增强模型可以使用完整题目—知识点关系与额外特征，现代基线目前使用代表知识点接口。相同输入的增强 FC-HGNN 与去超图消融更适合识别超图本身的贡献；跨模型结果应同时注明可用信息、参数量和时间成本，不能将全部差异归因于超图。

## 下一轮的优先补项

1. **首先接入官方 DGEKT，重点在 ASSIST17 上对照。** 官方仓库与当前数据直接重合，能优先补齐缺失的超图竞争者。移植时保留原有超图、转移图和蒸馏，而不是另写同名近似模型；作答转移图只由训练响应构建。另核查仓库许可和论文/代码版本差异。[作者代码](https://github.com/Yumo216/DGEKT)
2. **通用强基线补 DTransformer；错误与不确定性方向补 UKT。** DTransformer 作者代码覆盖 ASSIST17；UKT 的官方实验包含 NIPS34，与本轮 Eedi 数据方向相接。二者分别检验对比诊断与概率不确定性机制，不能用简单辅助损失或 Beta 头替代其完整方法。[DTransformer 作者仓库](https://github.com/yxonic/DTransformer)、[UKT 原论文](https://ojs.aaai.org/index.php/AAAI/article/view/35007)、[UKT 作者仓库](https://github.com/UncertaintyForKnowledgeTracing/UKT)
3. **若继续探索多尺度超图，优先补 HyperKT；若探索层级知识迁移，再补 MHAKT。** 前者与现有机制最接近，后者利用额外知识领域层级，需要先确定 XES/Eedi 层级如何对应原方法，保持所有比较模型的信息条件明确。[HyperKT](https://doi.org/10.1109/TNNLS.2024.3386810)、[MHAKT](https://doi.org/10.1145/3803860)

后续受控比较需要统一学生划分与真实作答事件评分、明确多知识点预测聚合方式、充分训练与同等验证调参预算、跨种子结果和以学生为单位的配对置信区间。应在完整或明确固定的基准协议上比较直接竞争者，并验证错误类 PR-AUC、决策收益与校准；一次 AUC 胜出或多数类 Accuracy/F1 尚不足以判断模型的整体能力。

本轮最合适的表述是：**新数据上的受控模型比较、超图贡献消融与错误敏感决策验证**。是否值得继续算法路线，应依据本轮实际结果及上述后续强基线的证据判断。
