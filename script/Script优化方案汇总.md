# Script 优化方案汇总（结合课程关系预学习与约束增强）

当前 script 在 data_abc_0.01 / data_abc_0.1 上 Test_AUC 约 0.59–0.63，低于或接近 LSTM/GNN；且主训练已改为 pass/fail 监督、课程级评估、按 (u,i) 划分。下面结合《课程关系预学习与约束增强方案》给出**几版**可选的优化方案，每版是一个完整可实施的组合。

---

## 方案一：同模块约束负样本（最小改动，方案 B）

**目标**：预训练阶段用「同模块优先」的负样本，提升课程表示的区分度，主训练沿用现有 pass/fail。

| 项目 | 内容 |
|------|------|
| **课程关系** | 仅用 OULAD 的 code_module（AAA/BBB/CCC），不做额外预学习。 |
| **预训练** | 用 `ConstrainByModuleSampler` 替代 `RandEdgeSampler`：以概率 p_module（如 0.7）从**与正样本课程同模块**的课程中采样 fake_i，否则均匀采样。需从节点 id 或数据中恢复 course_id→module。 |
| **主训练** | 不改：仍用 pass/fail BCE + pos_weight，评估仍为课程级。 |
| **改动文件** | `utils.py`：课程–模块映射 + `ConstrainByModuleSampler`；`pretrain.py`：替换 sampler，每 batch 传入 `batch_data['idx'][:,1]`。 |
| **预期** | 预训练表示更能区分「同模块内不同课程」，主训练 Test_AUC 有望小幅提升（约 +0.01–0.02）。 |
| **难度** | 低。 |

---

## 方案二：课程共现 + 难负样本（方案 A）

**目标**：用「学生选课共现」定义课程相似度，预训练用难负样本（与正样本课程相似的 fake_i），主训练不变。

| 项目 | 内容 |
|------|------|
| **课程关系** | 从 train 边统计课程共现矩阵 C[i][j]，归一化为 sim(i,j)；可选再对课程做小规模 Node2Vec/ GNN 得到课程嵌入。 |
| **预训练** | 用 `ConstrainedCourseSampler`：对当前 batch 的每个正样本课程 i，按 sim(i,·) 加权采样 fake_i（可加温度 τ 控制难度），替代均匀负采样。 |
| **主训练** | 不改。 |
| **改动文件** | `utils.py`：共现统计 + `ConstrainedCourseSampler`；`pretrain.py`：替换 sampler；数据侧可在 script 内从 `ml_oulad.csv` 统计或预计算存成文件。 |
| **预期** | 对比学习更有区分度，课程表示更细粒度，Test_AUC 有望再提升一档。 |
| **难度** | 中。 |

---

## 方案三：B + A 分阶段（先模块后共现）

**目标**：先上同模块约束（方案一），验证有效后再加共现难负样本（方案二），便于消融。

| 阶段 | 内容 |
|------|------|
| **第一阶段** | 实现方案一（同模块 sampler），跑 pretrain + main，记录 Test_AUC/AP。 |
| **第二阶段** | 在方案一基础上加课程共现与 `ConstrainedCourseSampler`：可设计为「以概率 q 用共现加权采样、以概率 1-q 用同模块采样」，或「同模块内再按 sim(i,·) 加权」。 |
| **开关** | 建议 `--augment_constraint none|module|cooccur|both`，便于对比 none / module / cooccur / both。 |
| **预期** | 两阶段都可单独评估，both 通常优于单一。 |
| **难度** | 中（先 B 后 A，代码可复用）。 |

---

## 方案四：预训练用约束负样本 + 主训练多任务（link + pass/fail）

**目标**：预训练用方案一或二的约束负样本；主训练在现有 pass/fail 之外，保留一点 link 对比作为多任务，加强表示。

| 项目 | 内容 |
|------|------|
| **预训练** | 同方案一或二（模块或共现约束负样本）。 |
| **主训练** | Loss = L_pass + λ·L_link。L_pass = BCE(pos_prob, label_01)（现有）；L_link = BCE(pos_prob, 1) + BCE(neg_prob, 0) 对同一 batch 的 pos/neg。λ 小（如 0.1–0.3），避免冲掉 pass/fail。 |
| **注意** | 主训练仍需构造 neg 边（fake_i），因此需保留或接入约束 sampler；若用方案一/二，主训练侧也可用同模块或共现负样本。 |
| **预期** | 表示既拟合 pass/fail，又保留「真边 vs 假边」的对比，可能提升泛化。 |
| **难度** | 中高。 |

---

## 方案五：课程关系预学习 + KL 分布约束（方案 C，进阶）

**目标**：显式做课程关系预学习，并在增强/负采样上施加 KL 分布一致性。

| 项目 | 内容 |
|------|------|
| **课程关系** | 用共现或课程子图得到 P(j|i)（如 softmax(sim(i,j)/τ)）。 |
| **预训练** | 负样本按 P(j|i) 采样；loss 在原对比 loss 上加 λ·KL(P || Q)，Q 为模型对负样本的预测分布（在候选 j 上 softmax）。 |
| **主训练** | 不改，或仅用约束负样本做 L_link 时再考虑 KL（通常先只在 pretrain 做）。 |
| **预期** | 增强分布与课程关系一致，理论最贴近老师说的「分布一致性」；实现和调参成本高。 |
| **难度** | 高。 |

---

## 方案六：仅主训练侧增强（不改预训练）

**目标**：预训练保持现状（或仅换为方案一），**主训练**引入课程关系：用约束负样本或课程级正则。

| 项目 | 内容 |
|------|------|
| **预训练** | 可选：保持当前或只做方案一（同模块负样本）。 |
| **主训练** | 当前主训练已无 link loss，只有 pass/fail；若希望「带约束」只体现在主训练，可：(1) 在课程级 loss 上加一项：同模块 (u,i) 的表示距离要小、不同模块略大（对比/三元组式）；或 (2) 不做负样本，只做「课程嵌入/共现」作为额外特征拼进表示再预测 pass/fail。 |
| **预期** | 改动集中主训练，易与当前 pipeline 兼容；收益取决于课程先验的利用方式。 |
| **难度** | 中。 |

---

## 推荐实施顺序（结合当前 script 较差）

1. **先做方案一**：同模块约束负样本，只动 pretrain + utils，风险小、可快速看 Test_AUC 是否提升。  
2. **若有效，再做方案二或方案三**：加入课程共现与难负样本，进一步拉高预训练质量。  
3. **若仍不足，考虑方案四**：主训练多任务（link + pass/fail），或方案六的主训练侧课程约束。  
4. **方案五（KL）**：作为可选进阶，在 A/B 稳定后再考虑。

---

## 与现有 script 的对接（统一）

- **utils.py**：课程–模块映射（方案一/二/三/六）、课程共现统计（方案二/三/五）、`ConstrainByModuleSampler` / `ConstrainedCourseSampler`，接口与 `RandEdgeSampler` 对齐（如 `sample(batch_dst_ids)` 返回与 batch 等长的负样本课程 id）。  
- **pretrain.py**：加载映射/共现；替换 sampler；若做 KL（方案五），在 loss 中加 KL 项。  
- **main.py**：若采用方案四，增加 L_link 与 λ；若采用方案六的课程约束，增加对应 loss 或特征。  
- **命令行**：建议统一 `--augment_constraint none|module|cooccur|both`（及可选 `--kl_weight`），便于复现与消融。

以上几版可根据时间与难度择一或组合实施；优先建议从**方案一**开始。
