# Script 修改方案：课程关系预学习 + 带约束的增强

根据老师建议，从两方面改进 script：（1）**先通过预学习得到课程之间的相关性/关系**；（2）**增强时采用带约束的增强**（非随机），约束可来自先验知识、人工规则或分布一致性（如 KL 散度）。以下给出几种可落地的修改方案。

---

## 一、现状简要

- **图结构**：节点 = 学生(u) + 课程(i)，边 = (u, i, ts, label)，课程节点对应 `course_key = code_module_code_presentation`（如 AAA_2013J）。
- **预训练**：`pretrain.py` 用 SpatialTemporal 做时空编码，对比学习里**正样本**为真实边 (u,i)，**负样本**为 (u, fake_i)，`fake_i` 由 `RandEdgeSampler` **均匀随机**从所有课程节点中采样。
- **增强**：预训练里还有 (1) 空间/时间视图通过 2 倍上下文 + Top_k 选子序列；(2) 负样本即上述随机 fake 课程。主训练 `main.py` 同样用均匀随机的负样本。

因此可改进点集中在：**课程关系预学习** + **负样本/视图的约束增强**。

---

## 二、方案概览

| 方案 | 课程关系预学习 | 带约束增强 | 实现难度 |
|------|----------------|------------|----------|
| A    | 课程共现/图上的课程相似度 | 负样本按课程相似度加权采样（难负样本） | 中 |
| B    | 同模块先验（AAA/BBB/CCC） | 负样本优先同模块 or 规则约束 | 低 |
| C    | 课程嵌入（预训练小模型） | KL 分布一致性：增强分布对齐课程关系分布 | 中高 |
| D    | 课程共现 + 模块先验 | 混合：规则 + 分布一致性 | 中 |

---

## 三、方案 A：课程共现预学习 + 难负样本采样

### 3.1 思路

- **课程关系**：用“共现”定义课程相关性——同一学生选过的课程对 (i, j) 共现，在训练集边上统计共现矩阵或共现图，得到课程相似度/邻接关系。
- **预学习**：先只对**课程子图**做一次预学习（或单独算课程嵌入），得到课程–课程关系表示（或课程嵌入），供主流程使用。
- **带约束增强**：负样本不再均匀随机，而是**按与当前正样本课程 i 的相似度加权采样**：与 i 越相似（共现越多）的课程 j 越容易被采为负样本（难负样本），对比学习更有区分度。

### 3.2 实现要点

1. **数据**：从 `ml_oulad.csv` 的 (u, i) 在 train 上统计课程共现矩阵 `C[i][j]`（或共现次数），可归一化为相似度 `sim(i,j)`。
2. **预学习（可选）**：用课程共现图或课程–课程边做一个小 GNN/Node2Vec，得到课程嵌入；或直接用共现向量作为课程关系先验。
3. **约束负采样**：实现 `ConstrainedCourseSampler`：
   - 输入：当前 batch 的正样本目标课程列表 `i_batch`，以及共现相似度/课程嵌入。
   - 对每个正样本课程 i，按 `sim(i, j)` 或与 i 的相似度分布做**加权采样**得到 `fake_i`（可设温度 τ 控制“难度”）。
4. **接入 script**：在 `pretrain.py` 与 `main.py` 中，将 `RandEdgeSampler(train_data['idx'][:,1])` 替换为上述 `ConstrainedCourseSampler`，在每 batch 传入当前 `batch_data['idx'][:,1]`，返回与 batch 等长的负样本课程 id。

### 3.3 优点与注意点

- 利用“学生选课模式”作为课程相关性，无需额外标注。
- 难负样本能提升对比学习的判别性。需防止过难（如几乎同分布）导致训练不稳定，可用温度或混合均匀采样做平滑。

## 四、方案 B：同模块先验 + 规则约束增强

### 4.1 思路

- **课程关系**：OULAD 有 `code_module`（如 AAA、BBB、CCC），同一模块的课程视为“更相关”。
- **预学习**：可以不做额外模型，仅构建**课程–模块**映射与**模块内/模块间**规则；若有需要，可加一个轻量课程嵌入（如用模块 one-hot + 现有特征）作为先验表示。
- **带约束增强**：用**人工规则**约束负样本或视图：
  - **规则 1**：负样本课程与正样本课程**同模块**的概率提高（例如 70% 同模块、30% 随机），使模型区分同模块内不同课程。
  - **规则 2**：或反过来，**只采同模块**作为负样本（严格约束），便于学习模块内细粒度差异。

### 4.2 实现要点

1. **课程–模块映射**：在转换阶段或 script 的 `utils.py` 里，从 `course_to_id` 的 key（如 `AAA_2013J`）解析出 `code_module`，建立 `course_id -> module`；若转换结果里没有直接存，可从 `ml_oulad.csv` 的节点 id 反查或从 `oulad.content` 的元数据列读取（若已写入）。
2. **ConstrainByModuleSampler**：
   - 以一定概率 `p_module` 只在**与正样本课程同模块**的课程中采样负样本，否则均匀采样；
   - 或 100% 同模块负样本（最强约束）。
3. **接入**：同方案 A，替换 `RandEdgeSampler`，传入当前 batch 的 `batch_data['idx'][:,1]` 与 `course_id -> module` 表。

### 4.3 优点与注意点

- 实现简单，不依赖复杂预训练；模块是 OULAD 天然先验。
- 若模块内课程很少，可适当混合跨模块负样本，避免过于简单。

## 五、方案 C：课程嵌入预学习 + KL 分布一致性增强

### 5.1 思路

- **课程关系预学习**：先用现有图或课程共现图训练一套**课程嵌入**（如 GNN 或 Node2Vec 只对课程节点，或用 (u,i) 边做 BPR/对比得到课程表示），得到课程分布或相似度矩阵。
- **带约束增强**：增强时要求**增强后的表示分布**与**课程关系先验分布**一致，用 **KL 散度**作为正则或约束损失：
  - 设先验分布：例如课程相似度矩阵导出的 P(j|i)（与 i 相似的 j 概率大）；
  - 模型对 (u,i) 的负样本 j 的预测分布为 Q(j|u,i)（可由 affinity_score 或采样概率构造）；
  - 约束项：在 batch 上对 KL(P || Q) 或 KL(Q || P) 做最小化，使增强/负采样“符合课程关系”的分布。

### 5.2 实现要点

1. **课程嵌入与 P(j|i)**：用共现或预训练得到课程嵌入后，用内积/softmax 定义 P(j|i) ∝ exp(sim(i,j)/τ)；或直接用共现统计归一化为 P(j|i)。
2. **Q(j|u,i)**：对每个 (u,i)，模型对候选负样本 j 的得分 s(u,i,j)，在候选集上做 softmax 得到 Q(j|u,i)。
3. **损失**：在 pretrain 的对比损失上加一项 λ * KL(P || Q)（或 reverse），在采样负样本时可按 P(j|i) 采样（带约束的负样本），同时用 KL 约束模型分布与先验一致。
4. **实现复杂度**：需要维护课程关系分布、在 batch 内或全局采样负样本并算 KL，代码量相对大。

### 5.3 优点与注意点

- 直接对应老师提到的“分布一致性（如 KL 散度）”的增强方式。
- 超参 λ、温度 τ 和候选集大小需要调节；可先在小规模数据上验证再推广。

---

## 六、方案 D：课程共现 + 模块先验混合（规则 + 分布）

### 6.1 思路

- **预学习**：同时利用（1）课程共现统计；（2）模块标签。得到课程相似度 `sim(i,j)` 与模块约束。
- **带约束增强**：
  - **规则部分**：负样本 50% 服从“同模块优先”规则（同 B）；
  - **分布部分**：在候选负样本上按 `sim(i,j)` 的分布采样，或加 KL 项使模型预测分布与 sim 分布一致（同 C 的简化版）。

这样既有人为规则（模块），又有数据驱动的分布（共现），且实现介于 B 与 C 之间。

### 6.2 实现要点

1. 建 `course_id -> module` 与课程共现相似度矩阵。
2. 负采样器：以概率 p 只从同模块中按 sim(i,·) 加权采样，以概率 1-p 从全集中按 sim(i,·) 加权采样（或均匀）。
3. 可选：在 pretrain 损失中加一项 KL( P_sim || Q_model )，与方案 C 相同但 P_sim 用共现导出。

---

## 七、推荐实施顺序

1. **先做方案 B**：只增加课程–模块映射与同模块负采样，改动小、易验证，能直接体现“先验 + 规则约束”。
2. **再做方案 A**：在 B 基础上加课程共现与难负样本采样，提升对比学习质量。
3. **若时间允许再做方案 C 或 D**：引入 KL 分布一致性，使“带约束的增强”更完整。

---

## 八、与现有 script 的对接点

| 文件 | 修改点 |
|------|--------|
| `utils.py` | 增加 `get_course_module_map()`、课程共现统计接口；实现 `ConstrainedCourseSampler` / `ConstrainByModuleSampler`，接口与 `RandEdgeSampler` 对齐（如 `sample(batch_dst_ids)` 返回与 batch 等长的负样本课程 id）。 |
| `pretrain.py` | 加载课程关系/模块映射；用新 Sampler 替代 `RandEdgeSampler`，每 batch 传入当前 `batch_data['idx'][:,1]`；若做 KL 约束，在 loss 中加 KL 项。 |
| `main.py` | 同 pretrain，替换负样本采样器，保持其余评估逻辑不变。 |
| 数据 | 若采用方案 A/C/D，可在转换阶段或 script 内从 `ml_oulad.csv` 统计课程共现；方案 B 只需课程–模块映射（可从 `course_to_id` 的 key 解析或从数据表读入）。 |

以上方案均保持现有预训练→主训练流程与评估方式不变，仅增加“课程关系”的利用与“带约束的增强”两部分的实现与开关（如通过 `--augment_constraint none|module|cooccur|kl` 选择）。
