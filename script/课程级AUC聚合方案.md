# Script 课程级 AUC 聚合方案

目标：让 Script 最终 result 里的 Test/Val/Train AUC 与 models 一致，都是**课程级别（每个 (u,i) 一个样本）**的排序能力。

---

## 一、前置：收集与聚合

1. **收集**：对每条边得到 `(u, i, ts, pos_prob, edge_label)`，其中 `edge_label` 来自 data 的 label（1=通过、-1→0=不通过）。
2. **聚合**：对同一 (u,i) 的多条边，按下面 **E** 或 **F** 规则得到一个**课程分数**，每个 (u,i) 一个 score、一个 label（label 同一 (u,i) 相同，任取一条即可）。
3. 在 (u,i) 级别上算 AUC / AP / Acc，写入 result。

设对 (u,i) 有边集合 \(E_{ui} = \{(ts_1, s_1), (ts_2, s_2), \ldots\}\)，其中 \(s\) 为 `pos_prob`，\(ts\) 为时间戳。

---

## 二、方案 E：时间加权平均

### 定义

课程分数 = **按时间加权的 pos_prob 平均**：

\[
\text{score}_{ui} = \frac{\sum_{e \in E_{ui}} w(ts_e) \cdot s_e}{\sum_{e \in E_{ui}} w(ts_e)}
\]

- \(s_e\)：该边的 `pos_prob`
- \(ts_e\)：该边的时间戳
- \(w(ts)\)：时间权重函数，**越大 ts 权重越大**（越晚的交互越重要）

### 权重形式（可选）

| 形式 | 公式 | 说明 |
|------|------|------|
| **线性** | \(w(ts) = ts\) | 时间越晚权重越大，实现简单；若 ts 跨很大范围，后期边会占主导 |
| **归一化线性** | \(w(ts) = (ts - ts_{\min}) / (ts_{\max} - ts_{\min} + \epsilon)\) | 把 ts 压到 [0,1]，再作权重，避免尺度敏感 |
| **指数** | \(w(ts) = e^{\alpha \cdot (ts - ts_{\min})}\) | \(\alpha > 0\) 时越晚权重越大；\(\alpha\) 越大越“只看最近” |
| **平方** | \(w(ts) = ts^2\) | 后期权重大于线性，更强调最近一段时间 |

### 含义

- “最终是否通过”更可能和**后期**行为相关，所以给近期交互更高权重。
- 既不像“只取最后一条边”那样丢掉历史，又突出近期，适合课程级排序。

### 实现注意

- 同一 (u,i) 的边可能来自同一时间段，ts 差异不大时，线性/指数差别不大；ts 跨度大时建议用归一化或指数。
- 若 ts 是“天”或“周”，可先减掉该 (u,i) 的最小 ts，再算 \(w\)，避免绝对时间影响。

---

## 三、方案 F：多数表决

### 定义

- **第一步（边级 0/1）**：对每条边用阈值 0.5 把 `pos_prob` 变成 0/1：  
  \(b_e = \mathbf{1}[s_e \ge 0.5]\)。
- **第二步（课程级 0/1）**：对同一 (u,i) 的所有 \(b_e\) 做**多数表决**，得到该课程的**离散预测** \(\hat{y}_{ui} \in \{0,1\}\)：  
  \(\hat{y}_{ui} = \mathbf{1}\bigl[\sum_{e \in E_{ui}} b_e > |E_{ui}|/2 \bigr]\)（超过一半为 1 则 1，否则 0；平局可约定为 0 或 0.5 再向下取整）。

### 用于 Acc

- 每个 (u,i) 有一个真实 label \(y_{ui}\)（0 或 1），一个预测 \(\hat{y}_{ui}\)。  
- **课程级 Acc** = 所有 (u,i) 上 \(\hat{y}_{ui} == y_{ui}\) 的比例。

### 用于 AUC / AP

- AUC/AP 需要**连续分数**，不能只有 0/1。
- **做法**：课程级分数用**该 (u,i) 所有边的 pos_prob 的平均**（或中位数）作为 \(\text{score}_{ui}\)，标签仍用 \(y_{ui}\)，在 (u,i) 上算 `roc_auc_score(score_ui, label_ui)` 和 AP。
- 即：**表决只用于 Acc**；“排序能力”仍用连续分数（平均 pos_prob）来算 AUC/AP，这样和 E 的分数含义一致，只是聚合方式不同。

### 含义

- 每次交互先做一个“通过/不通过”的硬判断，再按**多数天**的倾向决定这门课最终预测。
- 能削弱单次异常（某天模型特别高/低）的影响，适合希望“多数时段一致才判过”的场景。

### 实现注意

- 只有 1 条边的 (u,i)：表决结果就是该边的 0/1；分数仍用该边的 pos_prob。
- 平局（一半 0 一半 1）：可规定为 0，或规定为“取平均 pos_prob 再与 0.5 比较”得到 0/1。

---

## 四、E 与 F 对比小结

| 项目 | E. 时间加权平均 | F. 多数表决 |
|------|------------------|-------------|
| **课程分数（AUC/AP）** | 时间加权的 pos_prob 平均 | 所有边 pos_prob 的简单平均（表决不参与分数） |
| **课程预测（Acc）** | 分数 ≥ 0.5 则为 1 | 边级 0/1 再多数表决得到 0/1 |
| **侧重点** | 近期交互权重大 | 多数边“投票”一致 |
| **实现** | 需选 \(w(ts)\) 和归一化方式 | 需约定平局规则 |

两者都可与“按 (u,i) 一个样本”的 AUC/AP/Acc 流程对接；选定 E 或 F 后，在 script 里做“按边收集 → 按 (u,i) 聚合 → 课程级指标”即可。
