3 实验与分析

**3.1 实验设置**

3.1.1 数据集

本文实验基于英国开放大学（Open University，OU）远程开放学习场景下的 **开放大学学习分析数据集（Open University Learning Analytics Dataset，OULAD）**^[1]^。该数据集汇集了多门学分课程在学习管理系统中的注册信息、学习者属性与学习行为日志，广泛用于学习分析与教育数据挖掘研究。本文沿用语义一致的课程模块代号 **AAA～GGG**（与 OULAD 中 `code_module` 字段对应），并在整模块设定下合并多个开课实例（presentation，如 2013J、2014B 等）的日志；实例内的交互日期取为相对该实例开课日的天数，合并多实例时在时间戳编码中叠加实例分块索引，以避免不同班次日程的简单混叠，具体规则与预处理脚本一致。

在上述构图下，图 **并非**「课程知识点」同质网络，而是 **学生节点** 与 **虚拟学习环境（Virtual Learning Environment，VLE）站点节点** 之间的 **时序二部图**。其中，**VLE** 指课程在线平台（与 OULAD 中 Moodle 类环境相对应）中的资源或活动承载单元；**站点（site）** 与原始表 `vle.csv` / `studentVle.csv` 中的 **`id_site`** 对齐，通常对应某一可点击访问的学习对象（页面、测验、论坛等）。**节点**因此分为两类：（1）学生节点，附带人口学与修课背景等静态属性；（2）VLE 站点节点，附带活动类型等属性。**边**表示「某学生在某一相对日以一定点击强度访问某站点」的聚合交互；边携带时间戳，用于刻画行为随时间的演化。节点特征经类别编码与连续特征标准化后与模型维度对齐；边的标签在观测日志中均为正样本，训练时负样本由协议随机替换终点站点构造（见下节任务说明）。

本实验共构建 **AAA、BBB、CCC、DDD、EEE、FFF、GGG** 七个模块级数据集（基本信息见 **表 1**），用以验证 **教育场景时空图 Transformer（Educational Temporal Graph Transformer，EduTGT）** 的有效性。

**实验任务与场景含义。** 本文主实验 **不是** 静态图上的 **节点分类（node classification）**，而是在上述时序二部图上开展 **归纳式动态链路预测（inductive dynamic link prediction）**：在给定历史交互的条件下，判别候选三元组「学生–站点–时刻」所描述的访问是否会发生；负样本保持学生与时间不变、替换终点站点。其在教学平台上的直观含义包括：判断学习者在未来时间点是否会访问某学习资源、辅助资源推荐排序与路径引导，以及为学业预警等下游任务学习与时序一致的表征基础。

3.1.2 评价指标

为评估链路预测性能，采用 **受试者工作特征曲线下面积（Area Under the Receiver Operating Characteristic Curve，ROC-AUC，文中简称 AUC）**、**平均精度（Average Precision，AP）** 以及 **准确率（Accuracy，ACC）** 作为主要指标。其中，AUC 衡量总体排序能力；AP 侧重类别不均衡时的精度–召回综合表现；ACC 依赖固定判定阈值，对类别分布与阈值选取更为敏感。

3.1.3 对比模型与实现细节

为验证 EduTGT 的有效性，从典型 **时序图神经网络（temporal graph neural network，TGNN）** 基线与本文扩展变体中选取下列模型进行比较^[2–5]^。

1）**TGN**^[2]^：基于记忆模块与邻域聚合的动态图模型。

2）**TGAT**^[3]^：在时间轴上对历史邻居进行注意力加权的表示学习模型。

3）**JODIE**^[4]^：联合建模交互序列与节点嵌入轨迹的预测模型。

4）**ContraTGT（时空双路对比预训练基线）**^[5]^：采用空间–时间双路 Graph Transformer 编码，并结合对比式预训练与链路微调；负采样为均匀随机替换终点站点。

5）**EduTGT**：在 ContraTGT 主流程之上，训练阶段引入 **开课实例（presentation）** 关系矩阵，对负样本终点做偏置采样（**presentation-aware biased negative sampling**，与实现中的偏置负采样一致），以引入与课程结构相关的困难负例。

实验在 Ubuntu 22.04 下进行，采用 Python 3.12 与 **PyTorch（Python 开源深度学习框架）** 2.5.1；硬件为 **英伟达 GeForce RTX 3060 图形处理器（Graphics Processing Unit，GPU）**，驱动 **统一计算设备架构（Compute Unified Device Architecture，CUDA）** 12.4。

**3.2 结果分析**

3.2.1 模型性能比较

如 **表 2** 所示，在 OULAD 的 AAA、BBB、CCC、GGG 四模块上，将 EduTGT 与 TGN、TGAT、JODIE 及 ContraTGT 对比。整体上 EduTGT 在 AUC、AP 上稳定较优：四数据集平均 AUC 为 0.9581，相对 TGN、ContraTGT 分别提升 0.0074、0.0149；平均 AP 为 0.9548，相对 TGN、TGAT、ContraTGT 分别提升 0.0026、0.0133、0.0256，表明其在教育时序二部图上的链路判别与排序能力更强。

从分数据集的结果来看，EduTGT在AAA、BBB和GGG三个模块上均取得最优或接近最优的AUC和AP；其中，在BBB数据集上，AUC达到0.9791，体现了该模型在较大规模交互图（节点数7,636，边数1,139,085）上的有效性。在CCC模块上，TGAT的 AUC（0.9686）明显高于其他方法，说明纯时间注意力模型在特定模块分布下仍具有优势；但EduTGT在该模块上的AP（0.927）与ContraTGT基本持平，表明其在概率排序层面保持了稳定的性能。

在ACC指标上，EduTGT的平均值为0.8859，与ContraTGT（0.8845）基本一致，但低于TGAT（0.9113）。考虑到ACC指标依赖于固定阈值，对类别分布和决策边界更加敏感，而AUC和AP对不平衡样本的表现更为稳健，因此本文以AUC和AP作为主要评估指标。综合来看，EduTGT在多数模块上取得了更优的综合表现，验证了其时空双路建模和教育场景适配策略的有效性。

3.2.2 消融分析

为了评估模型中各部分的有效性，以 **对比式时空图 Transformer（Contrastive Temporal Graph Transformer，ContraTGT）** 为基准模型（时空双路 Graph Transformer 编码及对比预训练 + 链路微调框架，负采样为均匀随机替换终点）；在此基础上引入 **开课实例偏置负采样（presentation-biased negative sampling，PANS）** 及与之配套的教育场景训练设定，模型命名为 **教育场景时空图 Transformer（Educational Temporal Graph Transformer，EduTGT）**，实现中与 **EduTGT + PANS** 相对应；为进一步验证 **时空耦合（SpatioTemporal Coupling，STC）** 编码模块的贡献，在完整 EduTGT 基础上去除 STC，模型命名为 **EduTGT without STC（EduTGT−STC）**，表中记作 **EduTGT w/o STC**；同理，在完整 EduTGT 基础上去除 **课程实例先验（Course-instance Prior Encoding，CPE）** 编码模块，模型命名为 **EduTGT without CPE（EduTGT−CPE）**，表中记作 **EduTGT w/o CPE**。在 OULAD 的 **AAA、EEE、GGG** 三个模块上进行消融模型的实验分析，结果见 **表 3**。

由 **表 3** 可知，完整模型在三个数据集上的总体表现最优。以平均指标计，**EduTGT（EduTGT + PANS）** 的 AUC 与 AP 分别达到 0.9593 和 0.9504，相比 **ContraTGT**（0.9482/0.9370）分别提升 0.0111 和 0.0134，说明在教育场景中引入课程结构先验与改进负采样策略能够有效提升链路预测质量。与完整模型相比，去除 STC 后平均 AUC/AP 下降至 0.9228/0.9234，表明时空联合建模对捕获学生行为演化规律具有重要作用；去除 CPE 后平均 AUC/AP 进一步下降至 0.8136/0.7737，且在 AAA 与 EEE 上退化尤为明显，说明课程实例先验对教育动态图中的表示学习至关重要。

在分数据集层面，GGG 上完整模型 AUC 达到 0.9705，较 ContraTGT 提升 0.0177；AAA 上完整模型 AP 达到 0.9554，较 ContraTGT 提升 0.0056。尽管在 EEE 数据集上完整模型 ACC 低于 ContraTGT，但其 AUC 与 AP 仍保持提升，说明模型在阈值无关排序能力上更具优势。综合而言，STC 与 CPE 均为 EduTGT 的关键组成部分，二者协同可显著提升模型在教育时序图上的泛化与判别能力。
